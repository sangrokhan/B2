#### Summary
- Sangrok이 AI 서비스 및 토큰 전송 관점에서 일반 사용자 체감 성능과 직결되거나 네트워크 대전환 시 필요한 연구 주제가 무엇인지 폭넓게 질문
- 어시스턴트가 기존 tcp-ai-service-research 스킬(idle 후 cwnd 리셋 구조적 문제, RFC 2861, QUIC 유저스페이스 혼잡제어 idle-probe 실측)을 로드해 기존 연구 성과를 기반으로 답변
- 연구 영역을 3개 축으로 구조화 제시: (1) 전송/딜리버리 계층 — ITL jitter 체감 품질 영향, HTTP/2 vs HTTP/3(QUIC), RTO floor 재전송 지연 (2) 애플리케이션 인지 네트워킹 — 소켓 idle-hint, 토큰 단위 QoS/DSCP, KV-cache aware 라우팅, 멀티턴 connection persistence (3) 네트워크 운영자 관점 — N:1 incast 재정의, IW 재조정, ROI, 오남용 방지
- 각 항목마다 확보된 연구 성과와 공백 연구 주제를 구분해 정리
- 다음 조사 우선순위 3가지 선택지 제시 후 사용자 응답 대기 상태로 세션 종료

#### Decisions
- 세션 내 확정된 결정 없음 — 다음 조사 우선순위(①ITL/jitter 실측 ②eBPF/XDP 커널 힌트 조사 ③N:1 incast/AQM 비교) 중 사용자 선택 대기 중 세션 종료
