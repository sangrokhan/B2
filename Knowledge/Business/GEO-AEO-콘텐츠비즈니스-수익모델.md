# GEO/AEO와 콘텐츠 창작자 수익모델 변화

## 배경
SEO 다음으로 언급되는 GEO(Generative Engine Optimization), AEO(Answer Engine Optimization) 개념 파악 및, AI 검색 확산이 콘텐츠 창작자 수익구조에 미치는 영향 정리.

## 용어 정리

| 용어 | 최적화 대상 | 목표 |
|---|---|---|
| **SEO** | 구글/네이버 등 전통 검색엔진 SERP 순위 | 클릭 유도, 링크 랭킹 상승 |
| **AEO** | 스니펫, 지식패널, AI Overviews, 음성비서 | 클릭 없이 "직접 답으로 추출"되는 것 |
| **GEO** | ChatGPT/Perplexity/Gemini/Copilot 등 생성형 AI의 답변 생성 과정 | AI 답변 안에서 인용·근거로 사용되는 것 |

- 유사 용어 **LLMO**(LLM Optimization)도 GEO와 거의 동일 의미로 통용
- 2026년 초 기준 학계 합의된 정의는 없음, 벤더/실무자마다 용어 사용 다름

### 실무 시사점
- Q&A 구조, 명확한 정의문, 리스트/표 형태가 AI 파싱·인용에 유리
- 백링크보다 "다른 곳에서 얼마나 언급되는가(brand mention)"가 신뢰도 신호로 중요해짐
- AI가 답을 요약해버리는 "zero-click" 현상 심화

## 핵심 문제: 정보와 트래픽의 분리

- 기존 SEO 시대: 검색결과=링크 목록 → 사용자가 여러 사이트 클릭 → 방문 자체가 화폐(광고뷰/구독전환/브랜드인지)
- AI 답변 시대: 검색결과=AI가 이미 종합·요약한 답 → 클릭 필요성 자체가 구조적으로 감소
- AI가 콘텐츠의 "정보"는 가져가서 답변에 반영하지만, 그 대가로 오던 "사람 방문"은 발생하지 않음

## AI 크롤링 관련 수익모델 현황 (2026년 기준)

기존 광고 트래픽 기반 모델은 통하지 않고, 새로 등장 중인 모델들:

| 모델 | 방식 | 예시 |
|---|---|---|
| Pay-per-crawl | 사이트 소유자가 AI 크롤러 접근에 가격 설정, 미지불시 HTTP 402로 차단 | Cloudflare AI Crawl Control (하루 10억건+ 402 응답 전송 중, 2026-09-15부터 무료/신규 계정 광고페이지 기본 차단 전환) |
| 콘텐츠 라이선싱 플랫폼 | AI 기업이 학습/인용용 콘텐츠 접근권을 구매하도록 중개 | TollBit (분기 15억건+ 스크래핑 관리, 퍼블리셔 3000+) |
| 광고수익 배분형 | AI 답변에 광고를 붙이고 원출처와 수익 쉐어 | ProRata |
| 직접 라이선스 계약 | 대형 퍼블리셔가 OpenAI/구글 등과 개별 협상 | News Corp-OpenAI, Reddit-Google 등 |

**현실 평가**: 개인/소규모 사이트가 pay-per-crawl로 유의미한 수익을 내는 단계는 아직 아님 (수익보다 "접근 통제/협상력 확보" 의미가 큼). 라이선싱 플랫폼도 대형 퍼블리셔 위주로 작동, 소규모 참여시 단가 매우 낮을 가능성.

## 결론: 콘텐츠 창작자 관점에서의 대응 방향

기존 "글쓰기 → SEO → 방문 → 광고수익" 공식은 구조적으로 약화됨. 남는 선택지:

1. **여전히 클릭이 필요한 콘텐츠 유형으로 이동**: 실시간 정보, 계산기/인터랙티브 툴, 커뮤니티, 개인화 서비스, 원본 1차 자료, 유료 심층분석 — AI가 요약/대체 불가능한 것
2. **인용/언급을 간접 마케팅으로 전환**: AI가 출처를 자주 언급하면 전문가 브랜딩 효과 → 강의, 컨설팅, 뉴스레터 구독, 유료 커뮤니티 등 다른 채널로 수익화
3. **검색엔진 매개 없는 직접 관계 구축**: 이메일 뉴스레터 등 AI가 가져갈 수 없는 채널로 독자와 직접 연결

## 창업 아이디어 연결
콘텐츠비즈니스 방향 고려 시, 트래픽(클릭) 기반 광고 모델보다 "AI가 대신 못 하는 것"(전문성 브랜딩, 실시간/1차 자료, 직접 구독관계) 중심으로 처음부터 설계하는 것이 유리.
