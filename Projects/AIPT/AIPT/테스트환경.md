#### Summary
- API 테스트 목적으로 온디바이스 소형 LLM 메모리 요구사항 확인 요청

### 15:54 전체 회귀테스트 및 아키텍처/테스트 문서 원문 갱신

<!-- date: 2026-09-03 -->

#### Summary
- AIPT 코드 최근 수정 반영해 전체 회귀테스트 실행 및 테스트 이력·아키텍처 문서를 원문 갱신 방식(날짜 라벨 대신 실제 서술 교체)으로 정리
- Docker 4-service 스택(web/gateway/mock-server/local-llm) 재빌드, compose에서 이미 제거된 orphan quic-mock-server 컨테이너 정리
- pytest -m "not live" 497 passed/1 skipped, live 마커 포함 전체 513 passed/1 skipped 실측 확인, cache_protocol 관련 standalone smoketest 4종도 모두 실행해 PASS 확인 (캐싱 절감률 87.4%/86.5% 실측 재현)
- 회귀 중 실제 버그 발견: LOCAL_LLM_CTX_SIZE 기본값 4096으로는 20턴 누적 프롬프트가 1턴째부터 컨텍스트 초과 에러 → 32768로 상향 수정
- ARCHITECTURE.md/DESIGN.md/README.md/SRS-STD 문서/test-results 최신 실측치로 원문 갱신, quic_mock 백엔드 제거(afe6e29c) 관련 서술 완전 삭제하고 3-backend 구성으로 재기술

#### Decisions
- 문서 갱신은 날짜 라벨/변경이력 표기 방식이 아닌 원문 내용 자체를 최신 상태로 다시 쓰는 방식으로 진행
- 회귀테스트 범위는 live 마커 포함 전체(docker-compose 실 구동, 3-backend 실제 호출, 캐싱 절감률 e2e 재현까지)로 확정
- quic_mock 관련 문서 서술은 "지원 중단" 절로 남기지 않고 완전히 삭제, 현재 3-backend 구성으로만 재기술
